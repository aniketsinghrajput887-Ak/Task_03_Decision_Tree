# Decision Tree Classifier – Machine Learning Project

## Project Overview
This project uses a Decision Tree Classifier to predict bank marketing outcomes using the Bank Marketing Dataset.

## Objectives
- Perform data preprocessing.
- Handle categorical variables using encoding.
- Train a Decision Tree Classification Model.
- Evaluate model performance.
- Visualize the Confusion Matrix and Decision Tree.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
Bank Marketing Dataset containing 4,521 records and 17 original columns.

## Machine Learning Model
- Algorithm: Decision Tree Classifier
- Criterion: Gini
- Maximum Depth: 5
- Train-Test Split: 80:20

## Model Performance
- Accuracy: 89.17%

## Visualizations
1. Confusion Matrix
2. Decision Tree Graph

## How to Run
1. Install the required libraries:
   `pip install pandas numpy matplotlib scikit-learn`
2. Run the Python file:
   `python decision_tree.py`
